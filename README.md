# ROADVISION 3D — Pothole Birth Prediction System

Interactive web dashboard prototype built for the **Design Thinking** project (*Rapid Repair & Accountability* — Pothole Birth Prediction module).

## Live Dashboard
Open the live interactive dashboard here: https://kavinmugilff-commits.github.io/roadvision-3d/

## Features
- **Overview**: KPI cards, Coimbatore city risk heatmap, AI road surface crack detection overlay, road section risk table, and Pothole Birth Prediction gauge with 30-day deterioration progression.
- **Road Analysis**: Interactive crack detector with confidence slider, custom road photo upload, and I&C sensor telemetry (LiDAR, 3-axis accelerometer, moisture, ultrasonic void score).
- **Prediction Simulator**: Interactive what-if sliders and 30-day deterioration trajectory chart.
- **3D Road View**: Interactive 3D digital twin pavement elevation & cavity model.
- **Maintenance**: Proactive Repair Kit dispatch and automated SLA accountability tracking.
- **Reports & Settings**: CSV export, printable summary report, and 5G/LTE cloud sync settings.
